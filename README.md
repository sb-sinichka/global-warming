# AI-сортировщик отходов

в чём суть:  телеграмм-бот помогает сортировать мусор по фото. пользователь фотографирует предмет, ии сортирует его и рассказывает,что нужно сделать перед сдачей.

## поддерживаемые виды мусора

- пластик
- стекло
- бумага/картон
- биологические отходы

## использование

- `/start` и `/help` -- инструкция
- отправьте сообщение с фотографией для получения рекомендации

## установка

чтобы установить нужные библиотеки:
```
uv sync
```

## запуск

создайте файл `.env` и поместите в него токен бота:
```
TOKEN = <ваш токен>
```
для запуска бота напишите `uv run main.py`
